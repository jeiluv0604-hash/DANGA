# Prompt Injection Threat Model v1.1

## 1. 위협 모델 개요
외부 사용자 입력 또는 비정형 텍스트(리뷰, 코멘트, 메모)를 통해 시스템 프롬프트를 탈취하거나 강제 승인, 징계/해고 단정을 유도하는 공격을 방어합니다.

## 2. 방어 메커니즘
1. **XML 태그 격리**: 모든 비정형 텍스트는 <UNTRUSTED_BUSINESS_DATA> 태그로 감싸 컨텍스트에 주입.
2. **금지어 및 비난 필터 (GP-05)**: '절도', '횡령', '해고', '감원' 등 단정적/인사조치 키워드 감지 시 즉시 REJECTED 처리.
3. **결정론적 승인 강제 (GP-04)**: AI 출력의 pproval_required 필드는 프롬프트 지시와 무관하게 시스템 Safety Validator에서 항상 True로 강제.
